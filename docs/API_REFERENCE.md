# Aiota REST API Reference

The Aiota Cloud API is built on Django Ninja, providing high-performance, OpenAPI-compliant endpoints for edge appliance synchronization, neural vector search, health reporting, and marketing lead capture.

* **Base URL**: `https://aiota.akilinova.co.ke/api`
* **Interactive Swagger UI**: [https://aiota.akilinova.co.ke/api/docs](https://aiota.akilinova.co.ke/api/docs)
* **Auth Scheme**: Bearer Token (`Authorization: Bearer <appliance_token>`) for edge sync; Session Cookie for Console routes.

---

## 1. System Health & Diagnostics

### `GET /api/health`
Verifies API status and connectivity to the Qdrant Cloud vector cluster.

#### Response
```json
{
  "status": "healthy",
  "subdomain": "aiota.akilinova.co.ke",
  "qdrant": "connected"
}
```

#### Example
```bash
curl -s https://aiota.akilinova.co.ke/api/health | jq .
```

## 2. Neural Vector Search

### `POST /api/search`
Executes natural language semantic searches against the indexed video surveillance events using cosine similarity over Qdrant Cloud.

#### Request Body
```json
{
  "query_text": "white pickup truck moving through entrance gate",
  "site_id": "optional-site-uuid",
  "camera_id": "optional-cam-uuid",
  "min_confidence": 0.50,
  "limit": 10
}
```

#### Response
```json
{
  "query": "white pickup truck moving through entrance gate",
  "count": 1,
  "results": [
    {
      "event_id": "evt_48a92b11-9231-419b-bc32-1b8ef039ac81",
      "score": 0.8841,
      "primary_label": "vehicle",
      "confidence": 0.94,
      "camera_name": "CAM-01: Mombasa Road Highway Access",
      "site_id": "site_naivasha_ranch_01",
      "started_at": "2026-11-10T14:35:12Z",
      "snapshot_url": "/media/snap_highway_traffic.jpg",
      "clip_url": "/media/clip_highway_traffic.mp4",
      "zones": ["Main_Gate_Inbound"]
    }
  ]
}
```

#### Example
```bash
curl -X POST https://aiota.akilinova.co.ke/api/search \
  -H "Content-Type: application/json" \
  -d '{"query_text": "cashier checkout till queue", "limit": 5}' | jq .
```

## 3. Edge Event Ingestion

### `POST /api/events/ingest`
Ingests a localized detection event from an on-premise Aiota Box. Accepts multipart form data with the primary detection payload and optional micro-clip and snapshot files.

#### Headers
* `Authorization: Bearer <APPLIANCE_TOKEN>`

#### Form Parameters
| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `edge_event_id` | String | Yes | Unique ID generated by the edge appliance (e.g. `frigate_1708239012.394`) |
| `camera_identifier`| String | Yes | Camera identifier (e.g. `cam_gate_01`) |
| `primary_label` | String | Yes | Classification label (`person`, `car`, `truck`, `livestock`, etc.) |
| `confidence` | Float | Yes | Detection score between `0.0` and `1.0` |
| `zones_entered` | JSON String | No | JSON array of zones breached (e.g. `["Perimeter_Fence_North"]`) |
| `detection_payload`| JSON String | No | Full telemetry and bounding box dictionary |
| `started_at` | Float | Yes | UNIX epoch timestamp of event initiation |
| `ended_at` | Float | No | UNIX epoch timestamp of event completion |
| `snapshot` | Binary File | No | JPEG image file of keyframe (<150 KB) |
| `clip` | Binary File | No | 5-second MP4 event video clip (<1.5 MB) |

#### Response
```json
{
  "status": "ok",
  "event_id": "48a92b11-9231-419b-bc32-1b8ef039ac81",
  "created": true,
  "indexed": true
}
```

## 4. Appliance Telemetry Heartbeat

### `POST /api/appliances/heartbeat`
Edge appliances periodically submit hardware and link metrics to report operational health.

#### Headers
* `Authorization: Bearer <APPLIANCE_TOKEN>`

#### Request Body
```json
{
  "status": "online",
  "ssd_buffer_usage_pct": 34.2,
  "cpu_load_1m": 0.45,
  "ram_usage_pct": 42.1,
  "uplink_type": "4g_lte",
  "timestamp": 1794273000.0
}
```

#### Response
```json
{
  "status": "received",
  "appliance_id": "appliance_naivasha_box_01",
  "appliance_name": "Naivasha Primary Farm Box",
  "cloud_time": "2026-11-11T03:20:00.000Z"
}
```

## 6. Real-Time WhatsApp & Multi-Channel Incident Alerting

### `GET /api/alerts/rules`
Retrieves all configured alert rules across connected facilities.

#### Response
```json
[
  {
    "id": "2adb899d-5f2c-47f7-a9ed-ccb8e65fb98c",
    "name": "Mombasa Road Highway Freight and Vehicle Alert",
    "site_name": "North Pasture & Perimeter",
    "target_labels": ["car", "truck", "vehicle"],
    "zones": ["Main_Highway_Access"],
    "min_confidence": 0.75,
    "channel": "whatsapp",
    "phone_number": "+254 722 000 000",
    "is_active": true,
    "created_at": "2026-11-11T07:28:09Z"
  }
]
```

### `POST /api/alerts/rules`
Creates a new automated alert rule.

#### Request Body
```json
{
  "name": "Fuel Depot Night Unauthorized Access",
  "target_labels": ["person", "vehicle"],
  "min_confidence": 0.80,
  "phone_number": "+254712345678",
  "zones": ["Fuel_Depot_Perimeter"]
}
```

### `POST /api/alerts/test`
Dispatches an immediate verified test WhatsApp alert card with a CCTV snapshot to any phone number.

#### Request Body
```json
{
  "phone_number": "+254712345678",
  "channel": "whatsapp"
}
```

#### Response
```json
{
  "status": "success",
  "is_live_gateway": false,
  "recipient": "+254712345678",
  "click_to_chat_url": "https://wa.me/254712345678?text=...",
  "snapshot_url": "https://aiota.akilinova.co.ke/media/snap_highway_traffic.jpg"
}
```

### `GET /api/alerts/logs`
Retrieves recent alert delivery records and statuses (`sent`, `simulated`, `failed`).
